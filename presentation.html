Problem Statement & Objectives

Slide 2 of 5

Current Challenges

  • Helpdesks flooded with repetitive administrative inquiries.
  • Long wait times for students during admission peaks.
  • Manual email/phone response is slow & costly.
  • Commercial LLM APIs are expensive and hallucinate.

Project Solution

  • Deterministic offline-capable Python NLP Engine.
  • TF-IDF & Cosine Similarity confidence scores.
  • Structured JSON Dataset across 8 academic categories.
  • Dual Modes: Terminal CLI + Glassmorphism Web App.

System Architecture

Slide 3 of 5

1. Preprocessing

  • Lowercasing & Punctuation Cleanup
  • NLTK Tokenization (`word_tokenize`)
  • Lemmatization (`WordNetLemmatizer`)

2. NLP Engine

  • TF-IDF Matrix Calculation
  • Stop Words Removal (`english`)
  • Cosine Similarity Scoring ($\cos \theta$)

3. User Output

  • Real-time Confidence Badges
  • Contextual Action Followup Pills
  • Voice Input & Read Aloud Audio
